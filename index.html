Part 1

Install the mods

  1. Download r2modman

    r2modman is the free mod manager for PEAK. It keeps mods separate from your normal game, so plain PEAK still works from Steam.

    Download r2modman Setup (v3.2.21) Latest version page

    Get it only from the official GitHub page above, or from Thunderstore. If GitHub has a newer version, download the file named r2modman-Setup-…exe.

  2. Run the installer

    Open the file from your Downloads folder. Leave Only for me selected, click Next, then Install. r2modman opens by itself when it's done.

  3. Pick PEAK

    Type PEAK in the search box. Hover over the PEAK cover and click Select game.

  4. Click Import / Update

    On the profile screen, click Import / Update, then choose From code.

  5. Paste the code

    Paste the profile code from the top of this page and click Continue. Confirm the mod list it shows. When it asks for a profile name, type something like Harou PEAK and confirm. r2modman then downloads every mod, which takes a minute or two.

  6. Check the mod list

    After the import you land on the Installed tab. You should see about 38 mods, including PEAKLobbyBrowser and PEAKMatchmaking. Some mods show as disabled on purpose. Leave the switches as they are so you match Harou.

Part 2

Start PEAK with mods

  1. Open Steam first

    Make sure Steam is running and you're signed in. r2modman starts PEAK through Steam.

  2. Click Start modded

    Open r2modman, pick PEAK and your Harou PEAK profile, then click the blue Start modded button. A message says PEAK is launching via Steam. You can close it.

    Always start from r2modman

    If you press Play in Steam, PEAK starts without any mods and you won't be able to join a modded lobby.

  3. Check the main menu

    Mods are working when you see a Lobby Browser sign on the right and a Matchmake sign on the post.

  4. Join Harou

    When Harou hosts, accept his Steam invite or use Join Game. You can also open Lobby Browser and look for his lobby. Lobbies can hold more than 4 players thanks to PEAK Unlimited.

Help

If something goes wrong

PEAK opened but there's no Lobby Browser sign

You started the game from Steam. Close PEAK and click Start modded in r2modman instead.

The code says it's invalid or expired

Ask Harou for a fresh code. He makes one in r2modman with Export profile → Export to code.

I can't join, or the game says mods don't match

Harou probably changed his mods. Get his newest code, then go to Import / Update → From code. When it asks, choose to update your existing Harou PEAK profile.

How do I play normal PEAK again?

Press Play in Steam. Mods only load when you use Start modded in r2modman.

For Harou

Sharing a new code after changes

Any time you add, remove or switch off mods, make a new code and send it to everyone. At the bottom of r2modman, click Export profile → Export to code. The code is copied to your clipboard.
